The Challenge

GameScope is a personalized video game review aggregation simulation that helps users browse games based on their preferences. Rather than showing a single general rating, the prototype displays both a General Score (based on critic/community data) and a User Score (based on the user's selected genres, tags, ratings, wishlist, completed list, and favourite creators) — allowing the system to recommend games in a more personalized way.

My Contribution

Of a 5-person team, I was one of two people responsible for the UI/UX layer, while the other three built the underlying system and data logic. I handled the majority of the UI/UX implementation in Unity's UI Toolkit, with a teammate assisting on layout adjustments and colour choices. Specifically, I:

  • Built the majority of the interface in Unity UI Toolkit, including responsive layouts and hover interactions
  • Integrated the team's backend data and scoring logic into the interface, connecting the data pipeline and scoring system to UI elements
  • Conducted QA testing throughout implementation — identifying and fixing issues including a compile error in a TextField placeholder, an unsupported CSS selector in the stylesheet, a backwards CSV data read, and a missing dictionary write in the rating logic
  • Converted several classes to be compatible with UI Toolkit's architecture
  • Aligned UI decisions with the design system — SGD price formatting, a four-tier colour-coded scoring system, a wishlist cart icon, and ratings that only unlock after game completion

Team Contribution

Three teammates built the underlying system — the data pipeline and scoring logic. One additional teammate co-worked on UI/UX with me, helping realign layout elements and adjust the colour scheme.
